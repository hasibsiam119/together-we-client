# TogetherWe Client

Next.js 16 App Router frontend. This is an early scaffold (`src/app/page.tsx` is still empty), so establish patterns here instead of assuming feature code exists.

## Commands

- Install: `npm install` (npm; `package-lock.json` is the source of truth)
- Dev: `npm run dev` — also rewrites the managed block above
- Lint: `npm run lint` (`eslint` with no args; lints the whole repo)
- Typecheck: `npx tsc --noEmit` (there is no script for it)
- Production: `npm run build`, then `npm start`
- No test runner or test files are configured; do not invent `npm test`

## Stack constraints

- Next.js **16.4.6** ships version-matched docs in `node_modules/next/dist/docs/`; consult them before using App Router APIs. Route props use generated global helpers such as `LayoutProps<"/">` (see `src/app/layout.tsx`), not hand-written prop types.
- `cacheComponents: true` and `partialPrefetching: true` are enabled in `next.config.ts`. Uncached async data must be wrapped in `<Suspense>` or marked `"use cache"`, or `next build` fails with a blocking-prerender error. Read `01-getting-started/08-caching.md` first.
- `reactCompiler: true` — the compiler handles memoization; don't add `useMemo`/`useCallback` by default.
- Tailwind CSS v4 is CSS-first: tokens and theme mappings live in `src/app/globals.css` (`@theme inline`). There is no `tailwind.config.*` or `postcss.config.*`; Tailwind is wired via the `@tailwindcss/turbopack` loader rule in `next.config.ts`.
- UI is shadcn/ui with `"style": "base-nova"` (`components.json`) built on **Base UI** (`@base-ui/react`), not Radix. Add components with `npx shadcn add <name>`; don't paste Radix-based shadcn examples.
- `cn()` comes from the `cn` package (shadcn's `clsx` + `tailwind-merge` replacement) and is re-exported by `src/lib/utils.ts`. Generated UI components import `cn` from `"cn"` directly; app code can import from `@/lib/utils`.
- Path alias: `@/*` → `src/*`.

## Conventions

- Routes and layouts go under `src/app`; shared components under `src/components`; helpers under `src/lib`.
- Fonts are CSS variables set in `src/app/layout.tsx`: `font-sans` = Raleway, `font-heading` = Roboto. Use `font-heading` for display text.
- Brand logo is `public/TogetherWe Community Logo.png`. The filename contains spaces — encode it (`%20`) or import it instead of hardcoding the raw path.
- `next-env.d.ts` is generated by Next and gitignored; never edit it.
